# Healthcare-Data-Analysis

This project analyzes 10,000+ synthetic healthcare records to identify patterns in **disease occurrence, patient demographics, clinical measurements, treatment outcomes, hospital stays, readmissions, treatment costs, and patient satisfaction**.

The analysis helps compare outcomes across diseases and departments, identify readmission and length-of-stay patterns, examine clinical-variable relationships, track monthly patient admissions, and calculate key healthcare KPIs.

These insights can support **patient-care improvement, healthcare performance monitoring, resource planning, treatment evaluation, and data-driven decision-making**.
